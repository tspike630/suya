# 粟牙

浏览器里可玩的网页。作品名叫粟牙，主人公也叫粟牙。他是物理教师，带着八尺戒尺和一包抽不完的和天下。

对白、立绘、行走图和曲子来自森零制作组已经终止开发的《拾落星辰》（[Starvior](https://github.com/MorizeroDev/Starvior)）。主人公原名奥伦，地图上用世原的立绘和行走图。这一页把这个人改叫粟牙。

立绘：泺罗。行走图：Diffileft。音乐：Noveky（`Crystal`，以及作品里的 `20210206_7`、`whisper_`、`OBE_Loops`）。

没有收入 RPG Maker 地图块、素材商店音效，以及曲库里不属于制作组的曲子。说明见 `NOTICE.md`。

## 打开

网页：https://tspike630.github.io/suya/

本地：

```bash
python3 -m http.server 4173
```

然后打开 http://localhost:4173 。

## 操作

- 点场景里的人或底部的词，调查、说话、开门
- Enter、Z、空格或点对话框：下一句
- X：把这一句一次读完
- Esc：菜单

进度记在这台浏览器里。
